# Search ordering and report workflow

Load root `SKILL.md`, `knowledge/practice/SEARCHES_AND_RESULTS.md`, `knowledge/forms/PRIORITY_FORMS.md`, `templates/searches/SEARCH_ROUTING_CATALOGUE.json` and appropriate worksheet. Distinguish official HMLR prescribed forms from internal worksheets. Always use live official or authorised form/portal. For OS1/OS2 priority, record actual protection period, search from date, disposition and title; OS3 does **not** confer protection. For SIM use a properly scaled plan; OC1/OC2 differ. For K15 vs K16 verify relevant names/identity. For LLC1 check whether HMLR is the authority; CON29/CON29O provider-licensed text is NOT bundled. Reports on environmental, drainage and highways require appropriate provider/authority and scope.

Generate only ordered requests and factual result review with unresolved queries, not assumed search clearance. Keep completed client data in approved private matter storage, never in distributed templates; no automatic applications or fee payment.
