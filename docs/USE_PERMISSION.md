# Requesting permission to use this repository

The repository is public to read. Its publication is not a licence. The `LICENSE` requires prior written permission for any use, including evaluation, research, copying, adaptation and use with an AI agent. Professional work on a fee-earning matter should be treated as commercial use unless the copyright holder confirms otherwise in writing; commercial use needs separate written permission.

## Permission request checklist

Contact the copyright holder through the contact route shown on the GitHub profile or repository. Identify:

- the person and firm requesting permission;
- the intended activity: evaluation, research, internal training, or use on live client work;
- whether the work is fee-earning or otherwise commercial;
- which repository version, files and agent/platform will be used;
- whether content will be copied, modified, shared internally, or redistributed;
- the proposed period and any matter/client data handling arrangements.

Wait for a written response that expressly grants the intended scope before using, copying, adapting or asking an agent to process the repository. Retain the permission and any limits with the firm's approval records. Do not treat silence, a public URL, GitHub access, or an agent's ability to read files as permission.

## Request wording

```text
Subject: Permission request — Conveyancing England Legal Skill

I request written permission to use [identify version or commit] for
[evaluation / research / training / work on client matters] at [person or firm].

The work is [non-commercial / fee-earning or otherwise commercial]. We plan
to use [files/features] with [named coding agent or platform] in [workspace].
We will [copy / modify / share internally / not redistribute] the material.
The proposed period is [dates]. Matter information will be handled under
[firm policy / approved environment], and will not be added to the public repo.

Please confirm in writing whether this exact scope is permitted, any
conditions, and whether any separate permission is needed for commercial use.
```
