# Workbench v0.2.0 verification and known limits

Release: 20 November 2026. Verification includes new offline unittest cases covering pseudonymous matter records, audit integrity, document candidate extraction and comparison, second-charge triage, lender waivers, deadlines, accounting, HMLR and execution preflight, specialist gates, drafting, accessible HTML, handoff and CLI. These tests use **fictional** matter data. Automated tests passed: **70 unittest methods** (65 new workbench/lifecycle tests plus five retained lender-directory tests) on the overlay package in a local Python 3.11 environment. The end-to-end fictional walkthrough also passed (case initiation, document ingestion, conflicting buyer names, 2nd-charge flag, 21 issues, audit integrity, report, draft, accessible dashboard and CSV handoff). **No legal practitioner's sign-off** is claimed. The pre-existing full legacy suite was not executed against the complete original plugin source in this isolated overlay build.

Testing a skill-only package does not imply it can execute local Python from every ChatGPT host. Provider authentication for Microsoft, HMLR, Companies House, lenders and banking is not configured. No live provider submission, end-user acceptance test, external filing, correct legal action or regulatory certification has been performed. Existing test files are retained and must still be run in a complete repository before firm-wide deployment.

For solicitor acceptance: test with authorised anonymised real documents in a **firm-approved** workspace; compare every extracted fact and page to the original; inspect colour plans and execution manually; confirm live lender offer/Part 2/3 and submission route; test completion accounting against actual ledger; exercise correct HMLR form editions; verify statutory and contract deadlines; inspect Word/PDF renders; run accessibility testing; obtain firm DPO/IT approval and signed legal/editorial review.

Design limit: preservation of original lending/transfer instrument formatting is provided by the pre-existing Word placeholder filler only for documented supported cases; the new `draft` command creates original text drafts, not pre-signed lender certificates or exact-layout form copies.
