# Using this repository with a coding agent

Repository: https://github.com/tarunag10/conveyancing-legal-skill

## Before you start

This is a research and supervised-workflow project for England and Wales conveyancing. It is not legal advice, a substitute for a qualified practitioner, or a source of guaranteed current law. Check current law, lender instructions and firm requirements for each matter.

The repository is public to read, but publication does not grant permission to use, copy, adapt or run its contents. The `LICENSE` requires prior written permission for all use. Work on fee-earning client matters should be treated as commercial use unless the copyright holder confirms otherwise; it needs separate written permission. See [`docs/USE_PERMISSION.md`](docs/USE_PERMISSION.md) for a permission request checklist.

## Give a coding agent access

1. Obtain written permission for the intended use before asking an agent to inspect or use the repository.
2. Open a coding-agent workspace that can access GitHub repositories, then paste the repository link and the task prompt below. If the agent cannot open GitHub links, clone the repository or download its ZIP, then open the extracted folder.
3. Ask the agent to read `LICENSE`, `README.md`, `AGENTS.md`, `SKILL.md` and relevant modules before changing anything.
4. Keep changes on a separate branch or local copy. Review the diff before using or sharing changes.

Do not provide live client, identity, financial, privileged or confidential matter data unless the firm's policy explicitly approves that specific agent and workspace. Never commit such material to this public repository.

## Copy-paste task prompt

```text
Work in the repository at https://github.com/tarunag10/conveyancing-legal-skill.

I have written permission for this task. The permission and its limits are:
[quote or describe them; if permission is absent, stop]

First inspect LICENSE, README.md, AGENTS.md, SKILL.md and the relevant modules.
Then complete this task:
[describe the coding or documentation task]

Follow repository instructions. Keep the change focused. Report changes and
any checks run. Do not include real client or confidential matter data. Do not
treat stored legal research as current without checking authoritative sources
at the point of use. Do not make legal decisions, contact third parties, file
documents, exchange contracts or move funds.
```

See [`docs/PRACTICAL_MATTER_WORKFLOW.md`](docs/PRACTICAL_MATTER_WORKFLOW.md) for using the CLI as an evidence organiser. It does not provide legal sign-off.
